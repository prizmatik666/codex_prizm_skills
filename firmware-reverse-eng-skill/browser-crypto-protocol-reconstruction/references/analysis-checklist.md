# Browser crypto analysis checklist

- [ ] Hash and preserve original resources.
- [ ] Map UI validation, event handler, helper, endpoint, method, headers, and ordering.
- [ ] Separate plaintext, transform, hash, challenge response, envelope encryption, and transport encoding.
- [ ] Extract tables/index formulas statically; enumerate proven alternatives offline.
- [ ] Create deterministic vectors or semantic decrypt/verify checks.
- [ ] Record token/session/cookie handling without storing plaintext secrets.
- [ ] Label code, capture, offline validation, derivation, and unknowns separately.
